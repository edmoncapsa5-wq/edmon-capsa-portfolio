# MarginLatch — Scope-control workflow demonstration

**Status: Working prototype and proposed customized service. This example is fictional; it is not a paying-client case study.**

## The problem
A studio agrees to build five website pages with two revision rounds. Later, a client asks for a sixth page with a custom form. Is that an included correction or an additional deliverable? What should happen before the work starts?

MarginLatch helps the studio document a **request → estimate → client decision → delivery → billing** workflow without adopting another subscription.

## Fictional change-request example

| Item | Example |
|---|---|
| Initial scope | Five pages; two design revision rounds |
| New request | Sixth landing page and custom form |
| Classification | Added work outside agreed scope |
| Additional effort | Four hours |
| Illustrative rate | $75/hour |
| Proposed additional fee | **$300** |
| Status | **Quoted; not approved** |
| Next action | Request explicit client approval before proceeding |

**Example client message:**

> Happy to add the extra landing page and form. Those items are outside our agreed five-page scope. The additional work is estimated at $300 and may move the delivery date by two working days. Would you like us to approve this as a separately priced addition, or keep the original scope and timeline?

This example does not grant permission to invoice or start work without genuine approval. Client contracts control the actual process.

## $99 founding offer: customized scope-control setup

- A tracker configured around the studio’s actual package tiers, revision allowances, and added-work categories.
- An editable branded change-request / approval document.
- Five client-facing email scripts for clarifying, quoting, securing approval, deferring, and following through.
- A one-page internal guide and one revision round within seven calendar days.

**Delivery:** Editable Excel and/or local HTML files. Proposed target: 24–48 hours after complete intake and cleared payment, subject to written agreement. **Not included:** hosted portal, e-signature, integrations, contract drafting, payment collection, or promises of recovered revenue. Browser-local storage is not encrypted.

## Fit check
If a studio already manages these decisions reliably in its project-management or invoicing software, another tracker may add friction. The first step is to ask how the studio handles extras today, and only recommend the setup where it genuinely simplifies the process.
