Workflow

What happens after the inquiry arrives

1
Capture
Normalize name, email, inquiry source and timestamp.
2
Duplicate check
Look for an existing organization/contact before creating another record.
3
Create or update record
Put the inquiry in the system of record.
4
Assign owner
Apply a clear ownership rule so the inquiry is not “everyone's job.”
5
Immediate acknowledgement
Send a professional response confirming receipt.
6
Follow-up scheduled
If there is no reply, create the next follow-up automatically.
7
Stop on response
Once the person replies, cancel automated follow-up and flag the owner.
