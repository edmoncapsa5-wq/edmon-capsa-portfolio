# Research & Decision Brief — Portfolio Sample

## Scenario
A manager is choosing between three scheduling tools for a five-person remote team. The request is not to collect the largest feature list; it is to reduce the decision to the criteria that materially affect adoption.

## Decision objective
Select a tool that is simple for a small team, supports shared scheduling, works remotely, and does not create unnecessary administrative overhead.

## Decision framework
| Criterion | Why it matters | Evidence to verify |
|---|---|---|
| Team scheduling | Core requirement | Shared/team booking capability |
| Calendar integration | Prevent double booking | Supported calendar providers |
| Time-zone handling | Remote-team requirement | Automatic time-zone conversion |
| Cost | Small-team constraint | Current plan/pricing terms |
| Administration | Adoption risk | Setup, permissions, user management |
| Export/portability | Reduces lock-in risk | Data export or migration options |

## Research method
1. Define the actual decision before searching.
2. Separate hard constraints from preferences.
3. Prefer current official product documentation for capabilities and pricing.
4. Record uncertainty instead of filling gaps with assumptions.
5. Compare only criteria that can change the decision.
6. Recommend an option only after the evidence supports it.

## Example executive summary format
**Status:** Three candidates reviewed against six decision criteria.

**Finding:** Two candidates satisfy the core scheduling requirements. The remaining decision turns on current pricing, administrative simplicity, and export options.

**Recommendation:** Verify those three items from current official documentation, then select the lowest-friction option that satisfies all hard constraints rather than paying for unused advanced features.

**Open item:** Pricing and feature availability are time-sensitive and must be checked at the time of the real decision.

## What this demonstrates
- research scoping
- source discipline
- decision-focused synthesis
- fact/assumption separation
- concise executive communication
- recommendation under uncertainty

*Portfolio demonstration. The example intentionally avoids fabricated current product facts; a live client assignment would use current cited sources.*
