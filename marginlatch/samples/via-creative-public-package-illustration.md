### Possible client wording (illustrative)

> Happy to prepare another logo proof. Our agreed package included up to three sets of revisions, so this additional proof would be £30 under the published package pricing. Please confirm that you'd like to add one more proof at £30, and we'll confirm the timing before scheduling the work.

### Who does what?

1. Account/contact owner checks the exact signed proposal and revision count; the public site is not the governing contract.
2. Pricing owner confirms if the £30 extra-proof rate applies and any VAT/timeline consequences.
3. Client provides an explicit written acceptance.
4. Production owner only starts the addition after approval.
5. Billing owner receives the approval reference and, if invoiced, records the actual invoice ID.

**Where a lightweight setup may help:** if the existing process already handles each step, no extra system is needed. If approval decisions live in separate email threads and invoice handoffs are manual, a single request/status log may be useful.
