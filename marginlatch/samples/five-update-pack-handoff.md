## Illustrative question

An agency has delivered five eligible edits against a five-update pack. The client then requests a **sixth edit** and asks for it to be completed in the same week. Has the pack been fully used, and should this request be included, quoted separately, deferred, or handled under another agreement?

A compact trail can make the internal decision visible without replacing the existing portal:

| Check | Example record — not real |
| --- | --- |
| Original service | Five-update pack, £149, publicly advertised |
| Request | Sixth content edit after the five previous updates **if those were all counted as eligible uses** |
| Scope classification | **Pending review**: confirm pack balance, other applicable agreements, goodwill/support exceptions |
| Proposed fee | **Not set**: assess and quote only if the actual contract allows an additional charge |
| Delivery impact | **To be agreed**, no added delivery deadline promised |
| Client decision | **Not yet requested / not approved** |
| Billing checkpoint | If separately approved and billable, record the invoice reference after issuing an invoice |
| Ownership | Agency identifies who checks scope, quotes, records approval and sends billing evidence |

**Example internal decision message:**

> The client has asked for another content edit. Please confirm the update-pack balance and whether the request is covered by any existing agreement. If it is additional chargeable work, send a fresh fee and turnaround for approval **before** scheduling it. If it is included, mark it as included rather than invoicing it.

**Example client note — only after the agency confirms the scope:**

> Thanks for the requested update. We'll check it against the edits already included in your pack. If it falls outside the remaining allowance, we'll share the price and timing for your approval before carrying out any additional billable work.
